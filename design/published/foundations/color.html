The identity is one color — brand teal #00A5BD. It measures 5.9:1 on the dark surface but only 2.9:1 on the light one, so light mode steps to a darker tone of the same hue. --accent resolves to the same value as --brand; they stay separate names so interactive color can diverge from the wordmark later without a find-and-replace. --series-1 is a fill rather than text, so it targets the 3:1 non-text threshold instead of 4.5:1 — which allows a lighter step than --brand uses.

Sequential ramp — activity heatmap
Light — low → high
Dark — low → high

Monotonic in luminance, so the ordering survives greyscale. The dark ramp runs the opposite direction in lightness: zero recedes toward the dark surface, and max is the brightest step against it.

These token names are a runtime API. app/static/js/dashboard.js reads --text-secondary, --border, --series-1, --series-6, --good, --critical and --seq-0…--seq-5 via getComputedStyle at chart-render time. Renaming one breaks charts silently — no console error, just wrong colors. Two further constraints follow from it: --seq-0…--seq-5 must stay 6-digit hex literals, because hexToRgb() does parseInt(hex.replace("#",""), 16) — rgb(), oklch(), color-mix() and 3-digit shorthand all produce garbage. And --series-1 must stay a flat color, never a gradient, because Chart.js takes it directly as a fill string.
