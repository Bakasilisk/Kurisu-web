Message export

Exports messages from every channel and thread the bot can read over a window you pick (1–12 weeks, 4 by default), as a CSV with columns timestamp, channel, author, content, message ID, and attachment links — it contains message content, so handle the download accordingly. This is the only page that moves message content through this app: it is streamed live from Discord via the bot and never stored here. A finished export stays downloadable for 60 minutes; attachment links in it expire after roughly 24 hours, a Discord limit rather than this app's.
