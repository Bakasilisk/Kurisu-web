Growth

The dashboard draws four charts from four independent endpoints. Previously one failure blanked all four and left no indication of why; a slow one left an empty rectangle that was indistinguishable from a server with no data. State is now per box, which is why all three appear together above — that is a real arrangement, not a demo contrivance.

Loading

dashboard.js adds .is-loading to a box before its fetch and clears it on settle. The canvas goes visibility: hidden rather than display: none, so it keeps its box and nothing reflows when the chart lands. The wrap fills with --surface-2 at --radius-md and a shimmer sweeps across an ::after overlay.

The shimmer sits inside @media (prefers-reduced-motion: no-preference), so the static fill is what anyone who asked to avoid motion gets — the fill is the state, and the animation only decorates it. The heatmap uses the same pair of rules through .activity.is-loading, since it is a table rather than a canvas.

Error

showBoxError() inserts .chart-error as a child of the box, absolutely positioned at inset: 0 over --surface-1. This is why .chart-box and .activity carry position: relative — the overlay covers the dead chart rather than displacing it, so a failure doesn't change the height of the grid row.

Retry is the standard .button with its shadow removed and shrunk one step: inside a failed panel it's a recovery affordance, not the page's primary action. It re-runs only its own box's fetch — the other three keep whatever they already drew.

Charts header

Charts

The period selector used to sit alone above everything, which read as though it filtered the stat tiles too — it never did. Pairing it with the "Charts" heading on one row makes the scope visual, and the label says it in words as a backstop.

The <select> is disabled for the duration of a reload and drops to opacity: .6 with cursor: not-allowed, so changing period mid-flight can't stack four more fetches on the four already running. Under 640px the header stacks to a column and the selector left-aligns under the heading.

Bounded canvas

.chart-canvas-wrap is a fixed 260px tall, paired with maintainAspectRatio: false in dashboard.js. Left to their natural aspect ratios the four charts came out at four different heights, so the 2×2 grid never lined up and the page grew or shrank depending on how many bars a dataset happened to return. The fixed height also gives the skeleton and the error overlay a stable box to fill before any data exists.
